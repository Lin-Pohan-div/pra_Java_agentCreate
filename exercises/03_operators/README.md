# 03 運算子與三元運算子

> 難度：★　主題：運算子、三元運算子、邏輯

## 學習目標

- 會用 `%` 取餘數，並用它判斷倍數或奇偶
- 看得懂、也寫得出三元運算子 `條件 ? A : B`
- 會用 `Math.min` / `Math.max` 組合出範圍限制

## 觀念講解

### 算術與比較運算子

| 運算子 | 意思 | 例子 |
|---|---|---|
| `+ - * /` | 加減乘除 | `7 / 2` → `3` |
| `%` | 取餘數 | `7 % 2` → `1` |
| `== !=` | 相等、不相等 | `x == 0` |
| `< <= > >=` | 大小比較 | `x >= 18` |
| `&& \|\| !` | 而且、或者、不是 | `x > 0 && x < 10` |

`%` 很適合用來判斷倍數：`n % k == 0` 代表 `n` 是 `k` 的倍數。

```java
boolean multipleOf5 = n % 5 == 0;
```

小心負數：`-7 % 2` 的結果是 `-1`，不是 `1`。所以用「餘數等於 0」來判斷，比用「餘數等於 1」安全。

### 三元運算子

```java
條件 ? 條件成立時的值 : 條件不成立時的值
```

它是一個**運算式**，會產生一個值，可以直接 `return` 或指定給變數：

```java
int temperature = 31;
String feeling = temperature > 28 ? "hot" : "ok";   // "hot"

int min = a < b ? a : b;   // 取較小的那個
```

閱讀技巧：先看 `?` 前面的條件，再確認「成立」對應的是冒號**左邊**。

### Math.min 與 Math.max

```java
Math.max(3, 8)   // 8
Math.min(3, 8)   // 3
```

兩個函式可以巢狀組合。例如「至少 0 分」：

```java
int score = Math.max(raw, 0);     // 低於 0 就當 0
```

要同時限制上下界時，想清楚兩件事：**哪一層負責擋住下界、哪一層負責擋住上界**，以及每一層要跟哪個值比。用幾個數字代進去驗算，例如比範圍小、在範圍內、比範圍大各一個。

## 常見錯誤

- 用 `% 2 == 1` 判斷奇偶，遇到負數就出錯
- 三元運算子的兩個分支寫反
- 巢狀 `Math.min` / `Math.max` 時，把上界和下界放錯層，或傳錯比較對象
- 用 `=`（指定）來比較，比較要用 `==`

## 延伸（選讀）

- `&&` 和 `||` 有**短路**特性：`a && b` 中只要 `a` 是 false，`b` 根本不會被計算。所以 `s != null && s.isEmpty()` 不會丟出 NullPointerException。
- Java 21 起有 `Math.clamp(value, min, max)` 可以直接限制範圍。
