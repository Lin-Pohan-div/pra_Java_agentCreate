# 08 巢狀迴圈

> 難度：★★　主題：巢狀迴圈、StringBuilder、組合

## 學習目標

- 理解巢狀迴圈的執行順序：外層走一步，內層跑完一整圈
- 會控制內層迴圈的起點，避免重複計算或「自己配自己」
- 會用 `StringBuilder` 組出有分隔符號的字串，而且頭尾不多出分隔符號
- 會用條件篩選要累加的項目

## 觀念講解

### 執行順序

```java
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        System.out.print("(" + i + "," + j + ") ");
    }
}
// (0,0) (0,1) (0,2) (1,0) (1,1) (1,2)
```

內層總共執行了 `2 × 3 = 6` 次。追蹤巢狀迴圈時，把 `(i, j)` 一列一列寫出來最可靠。

### 內層起點決定「配對」的種類

假設有 A、B、C 三個人，要兩兩握手：

| 內層起點 | 產生的配對 | 意義 |
|---|---|---|
| `j = 0` | AA AB AC BA BB … | 有序，含自己 |
| `j = i` | AA AB AC BB BC CC | 無序，含自己 |
| `j = i + 1` | AB AC BC | 無序，不含自己（握手數） |

先決定題目要的是哪一種，再決定起點。用小數字手算驗證：3 個人握手應該是 3 次。

### 分隔符號問題

把幾個項目用空白（或逗號）接起來時，項目之間的分隔符號比項目數量少一個。兩種常見寫法：

```java
// 寫法一：不是第一個項目時，先補分隔符號
StringBuilder sb = new StringBuilder();
for (int i = 0; i < words.length; i++) {
    if (i > 0) {
        sb.append(", ");
    }
    sb.append(words[i]);
}

// 寫法二：每個項目後面都加，最後再修掉尾巴
// （用空白當分隔符號時，可以用 trim()）
```

### 篩選後累加

```java
int evenSum = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        evenSum += i;          // 加的是 i 本身，不是加 1
    }
}
```

注意 `total++`（數個數）和 `total += i`（加總數值）的差別。

## 常見錯誤

- 內層迴圈起點錯了，把同一組算兩次，或把「自己和自己」也算進去
- 組字串時項目黏在一起，或尾端多出分隔符號
- 該加總數值時寫成計數，或反過來
- 迴圈上下界的 `<` / `<=` 搞錯

## 延伸（選讀）

- `String.join(", ", list)` 可以直接處理分隔符號問題。
- `n` 個東西兩兩配對的數量是 `n × (n - 1) / 2`，可以用來驗算迴圈的結果。
